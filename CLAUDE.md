# Состояние проекта (Memory Bank / project brief)

Используй паттерн **Memory Bank** (краткий бриф + активный контекст + прогресс + задачи) и единый файл **`PROJECT_STATE.md` в корне репозитория** как «источник правды» для ИИ.

## Обязательные действия

1. **Перед существенной работой** открой `@PROJECT_STATE.md` (или создай по шаблону ниже, если файла нет).
2. **После завершения задачи или заметного изменения кода/архитектуры/плана** обнови `PROJECT_STATE.md`: что сделано, статусы задач, актуальный фокус, следующий шаг.
3. Не дублируй в правилах длинные выдержки из `PROJECT_STATE.md` — держи факты в файле, в чате ссылайся на него.

## Правила работы с таблицей Задач

- **Никогда не удаляй строки** из таблицы Задач. Только меняй статус и заполняй дату завершения.
- Строки со статусом `done` остаются в таблице навсегда — это история.
- При добавлении новой задачи заполни колонку **Начало** (дата сегодня в формате YYYY-MM-DD).
- При завершении задачи: статус → `done`, заполни колонку **Завершение**.
- Формат таблицы задач: `| Задача | Статус | Начало | Завершение | Примечание |`

## Правила для раздела «Сделано»

- Раздел «Сделано» содержит **только крупные завершённые блоки программы** (модули, подсистемы, ключевые фичи) — не отдельные задачи.
- Не удаляй и не переписывай существующие пункты — только добавляй новые.
- Если блок был изменён/доработан — обнови описание строки, но не удаляй её.

## Структура `PROJECT_STATE.md` (обязательные разделы)

Сохраняй кратко, маркированными списками — чтобы за один проход было видно картину.

| Раздел | Назначение |
|--------|------------|
| **Мета** | Название, одна строка «для чего проект», ссылка на репо/доки при необходимости |
| **Стек и границы** | Языки, фреймворки, что входит в MVP и что сознательно не делаем |
| **Текущий фокус** | 1–3 пункта: над чем работаем сейчас |
| **План** | Ближайшие шаги по порядку (можно нумерованный список) |
| **Сделано** | Завершённые вехи (коротко, с датой завершения) |
| **Задачи** | Таблица или список с **статусом**: `todo` / `in_progress` / `done` / `blocked` + при `blocked` — причина |

### Шаблон для нового файла

```markdown
# PROJECT_STATE

**Проект:** …  
**Зачем:** …

## Стек и границы
- …

## Текущий фокус
- …

## План
1. …

## Сделано
- …

## Задачи
| Задача | Статус | Начало | Завершение | Примечание |
|--------|--------|--------|------------|------------|
| … | todo | YYYY-MM-DD | — | … |
```

## Связь с AGENTS.md

Если в репозитории есть **`AGENTS.md`**, не повторяй в нём длинный прогресс — достаточно ссылки: «Актуальное состояние и задачи: см. `PROJECT_STATE.md`».
