# Промпт: аватар-помощник «Елена Головина» — стиль презентации «На одной волне»

Аватар по нашему образцу (как `avatar-kremneva` / `avatar-putilin`). Вход — фото
`NAT_5073.jpg` (женщина, русый боб, серый пиджак, белая рубашка). Стиль — тот же
полу-мультяшный cel-shaded портрет, что у остальных аватаров-помощников.

## Как использовать
- **Режим:** image-to-image / «по референсу лица». Вход — реальное фото Головиной.
- Промпт задаёт **только стиль**; лицо берём с фото (**сходство обязательно**).
- Likeness — **высокое** (denoise ~0.35–0.5 для SD; Midjourney `--cref <фото> --cw 100`;
  GPT-image/Sora — «сохрани черты лица с фото, стилизуй только рендер»).
- **Фон — СПЛОШНОЙ ЯРКО-ЗЕЛЁНЫЙ (хромакей #00FF00)**, НЕ прозрачный, НЕ шахматка. Зелёнку
  уберём кодом (как с `para-cafe` / прошлым аватаром). Рамку/гекс/свечение добавим в коде.
- **Соотношение сторон — портрет ~1007×1291 px (W×H), H:W = 1291:1007** — как `avatar-kremneva.png`
  (рамка-гекс и появление в коде рассчитаны под портрет-бюст).

## Негатив (что НЕ нужно)
- Другой человек / искажённое лицо / изменённая личность.
- Длинные распущенные волосы / хвост (у неё **боб до подбородка**), тёмные волосы.
- Скрещённые руки / поясной кадр / 3-4 разворот (нужен именно бюст до плеч, анфас).
- **Прозрачный фон / шахматка / клетки** — нужен именно СПЛОШНОЙ зелёный.
- Зелёные отсветы на коже/волосах/одежде; зелёный/лаймовый в одежде.
- Рамка, гексагон, круг, подпись, водяной знак, текст, логотип — **не добавлять** (сделаем в коде).
- Запечённое свечение/ореол/неон-rim-light по краю фигуры — **не добавлять** (контур/пульс — в коде).
- Пере-реалистичные поры/фотореализм; засвет; размытие краёв.
