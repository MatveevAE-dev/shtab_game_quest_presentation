# Инструкция: генерация UI-иконок в стиле «Штаб по защите бизнеса»

## Как использовать

Скажи Claude Code:
```
Прочитай инструкцию из файла prompts/03_icon_style.md и нарисуй SVG-иконку
для достижения «[название достижения]». Добавь её <symbol> в index.html и
покажи бейдж в панели достижений.
```

Например:
```
Прочитай prompts/03_icon_style.md и сделай иконку для достижения
«Прошёл первую проверку и не поседел». Тип — щит. Цвет — gold.
```

---

## Инструкция для Claude Code

Ты — иконочный дизайнер UI, работающий по методологии «единая неоновая линейная система» (line-icon system). Твоя задача — нарисовать одну SVG-иконку под конкретный смысл (достижение/навык/ресурс), которая визуально неотличима от уже существующих иконок проекта.

### Ключевой принцип

**Иконка = один контур, один смысл, один стиль.** Новая иконка должна выглядеть так, будто её нарисовал тот же человек, что и весь набор: те же толщина линии, скругления, сетка 24×24, минимализм. Не добавляй заливки, тени, градиенты, текст.

---

### Шаг 0: Изучи эталон

Открой `index.html`, найди блок `<svg width="0" height="0" ...>` с `<symbol>`-иконками. Это источник правды по стилю. Извлеки и держи перед глазами параметры:

- `viewBox="0 0 24 24"` — единая сетка у всех иконок;
- классы отрисовки: `.ic` (общая), `.skill .ic`, `.ach-badge .ic` — смотри `stroke`, `stroke-width`, `fill`;
- существующие id: `ic-idea`, `ic-motiv`, `ic-plan`, `ic-req`, `ic-reward`, `ic-pin`, `ic-book` — НЕ дублируй смыслы.

### Шаг 1: Зафиксируй обязательные параметры стиля

Любая новая иконка ДОЛЖНА соответствовать:

| Параметр | Значение |
|----------|----------|
| Холст | `viewBox="0 0 24 24"` |
| Заливка | `fill:none` (только контур) |
| Толщина линии | `stroke-width` 1.6–1.7 |
| Концы/стыки | `stroke-linecap:round; stroke-linejoin:round` |
| Цвет (навыки/HUD) | cyan `#3fd0ff` (через класс, НЕ хардкодь в symbol) |
| Цвет (достижения) | gold `#ffcd6b` (через класс `.ach-badge .ic`) |
| Безопасное поле | рисуй внутри 3–21 (отступ ~3px от краёв) |
| Сложность | 1–3 контура максимум, без мелких деталей < 2px |

Цвет и толщину задаёт CSS-класс (`.ic`, `.ach-badge .ic`) — внутри `<symbol>` пиши ТОЛЬКО геометрию (`<path>`, `<circle>`, `<rect>`, `<line>`, `<polygon>`), без атрибутов `fill`/`stroke`.

### Шаг 2: Подбери метафору под смысл

#### 2.1. Раздели смысл на «предмет-символ»
- Что одним предметом передаёт достижение? (книга = прочитал, щит = проверка пройдена, молния = энергия, флаг = старт/финиш).
- Выбирай узнаваемый силуэт, читаемый в 22×22px.

#### 2.2. Проверь читаемость
- Силуэт понятен без подписи? Если нет — упрости до одного предмета.
- Нет ли уже такого символа в наборе? (не делай вторую «молнию»).
- Помещается в безопасное поле 3–21 без обрезки?

### Шаг 3: Нарисуй геометрию

- Стартуй от простых примитивов: `<circle>`, `<rect rx="...">`, прямые `<path>`.
- Кривые — кубическими/квадратичными Безье, плавные (стиль «скруглённый», не угловатый).
- Замкнутые формы закрывай `Z`.
- Координаты — десятичные, в пределах 0–24.

### Шаг 4: Встрой в проект

1. Добавь `<symbol id="ic-[смысл]" viewBox="0 0 24 24">…</symbol>` в общий svg-набор (рядом с `ic-book`), с комментарием-подписью на русском: `<!-- [предмет] — достижение «[название]» -->`.
2. Добавь бейдж в нужную панель: `<button class="ach-badge" data-title="[название достижения]"><svg class="ic"><use href="#ic-[смысл]"/></svg></button>`.
3. Ничего не хардкодь по цвету — он придёт из класса.

### Примеры

**✅ Хорошо — чистый контур, один смысл, стиль набора:**
```html
<!-- открытая книга — достижение «Дочитал титул до конца» -->
<symbol id="ic-book" viewBox="0 0 24 24">
  <path d="M12 6C10.4 4.7 8.4 4.2 6.4 4.2 5.5 4.2 4.8 4.4 4 4.7v13c.8-.3 1.5-.5 2.4-.5 2 0 4 .5 5.6 1.8 1.6-1.3 3.6-1.8 5.6-1.8.9 0 1.6.2 2.4.5v-13c-.8-.3-1.5-.5-2.4-.5-2 0-4 .5-5.6 1.8Z"/>
  <path d="M12 6v12.8"/>
</symbol>
```

**❌ Плохо — заливка и хардкод цвета (ломает единый стиль):**
```html
<symbol id="ic-book" viewBox="0 0 24 24">
  <path fill="#ffcd6b" stroke="#000" d="..."/>  <!-- нельзя: fill, чужой stroke -->
</symbol>
```

**❌ Плохо — другая сетка и угловатость (выпадает из набора):**
```html
<symbol id="ic-book" viewBox="0 0 32 32"> <!-- нельзя: не 24×24 -->
  <polyline points="2,2 30,2 30,30"/>     <!-- острые углы, нет round -->
</symbol>
```

## Система достижений — поведение (ОБЯЗАТЕЛЬНО на всех слайдах)

Достижение — это не просто иконка, а сценарий. На любом слайде, где герой что-то «получает», ачивка ведёт себя одинаково. Понимай и воспроизводи этот цикл по умолчанию, без переспроса.

### Триггеры по слайдам

Достижение даётся НЕ по таймеру, а по **осмысленному действию** игрока на слайде. Один слайд = один триггер = одно достижение. Срабатывает один раз (флаг `…Fired`).

| Слайд | Достижение | Триггер (что должен сделать игрок) |
|-------|-----------|-------------------------------------|
| 0 — Титул | «Дочитал титул до конца» (книга) | навёл на «?» над героем И текст в тултипе **полностью допечатался** |
| 1 — Старт | «Придумал бизнес в душе, не забыл к обеду» (лампочка `#ic-idea`) | клик по объекту **Даниловский рынок** (его замок снят, всегда подсвечен) |
| 2 — Первые шаги | «Прошёл первую проверку и не поседел» | [определить] |
| 3 — Новые вызовы | «Согласование пройдено без потери нервов» | [определить] |
| 4 — Сложный кейс | «Собрал за одним столом тех, кто не созванивается» | [определить] |
| 5 — Финал | «Дошёл до Штаба раньше, чем до выгорания» | [определить] |

Принцип триггера: действие должно быть **осмысленным жестом по теме слайда** (наведение, клик по объекту, доведённое до конца взаимодействие), а не просто «прошло N секунд».

### Жизненный цикл ачивки (5 фаз)

1. **Триггер** — действие игрока из таблицы выше. По триггеру (один раз) запускается показ.
2. **Уведомление** — снизу по центру всплывает плашка: `[иконка достижения] + текст «Достижение разблокировано: «…»»`. Иконка в плашке — **ТА ЖЕ** SVG-иконка достижения (золото), НЕ эмодзи 🏆.
3. **Удержание** — плашка висит ~2.5 с (время прочитать).
4. **Полёт** — плашка улетает к панели игрока: текст гаснет, плашка ужимается до размера бейджа, летит в блок «Достижения». Дельта движения считается в рантайме: центр иконки уведомления → центр целевого бейджа (`getBoundingClientRect`).
5. **Сбор** — на месте бейджа появляется иконка (поп-вспышка). Бейдж до прилёта скрыт (класс `pending`). Наведение на бейдж → тултип с **той же** иконкой достижения + название.

### Инвариант единой иконки

Одно достижение = одна SVG-иконка, и она одинакова во ВСЕХ трёх местах: **уведомление**, **бейдж в панели**, **тултип бейджа**. Никаких 🏆-эмодзи как заглушки. Меняешь иконку — меняется везде (источник один: `<symbol id="ic-…">` + `<use href="#ic-…">`).

### Опорные классы и точки кода (в `index.html`)

| Элемент | Класс / id | Роль |
|---------|-----------|------|
| Уведомление | `.titul-ach` (`#titulAch`) | плашка снизу; `.show` — показ, `.fly` + `--dx/--dy` — полёт |
| Иконка в уведомлении | `.ach-fly-ico .ic` | золотой `<use>` нужной иконки |
| Текст | `.ach-text` | гаснет в фазе полёта |
| Список бейджей | `.ach-list` (`#achList`) | контейнер в панели игрока |
| Бейдж | `.ach-badge` | `.pending` — скрыт до прилёта; `.justgot` — поп-вспышка; `data-title` — название |
| Тултип | общий `tip` div + `.tip-ach-ico` | золотая иконка из `use href` бейджа |
| Тайминги | блок `finish()` в `<script>` | показ / полёт / сбор (мс) |

### Чек-лист «добавить достижение на слайд N»

1. Нарисуй/выбери иконку по правилам выше → `<symbol id="ic-[смысл]">` (без `fill`/`stroke`).
2. Бейдж в `#achList` этого слайда: `<button class="ach-badge pending" data-title="[название]"><svg class="ic"><use href="#ic-[смысл]"/></svg></button>`.
3. Уведомление с той же иконкой (`<use href="#ic-[смысл]"/>`) и текстом ачивки.
4. По триггеру слайда — запусти цикл (показ → удержание → полёт → сбор) тем же паттерном, что на титуле.
5. Проверь инвариант: иконка одинакова в уведомлении, бейдже и тултипе.

По умолчанию иконка встраивается прямо в `index.html` (symbol + бейдж). Если просят отдельный каталог иконок — сохрани в `prompts/icons_log.md` со структурой:

## SVG-исходники
\```html
<symbol id="ic-[…]" viewBox="0 0 24 24">…</symbol>
\```

### Важные правила

1. **Никаких `fill`/`stroke` внутри `<symbol>`** — цвет и толщину задаёт CSS-класс, иначе иконка выпадет из темы при смене акцента.
2. **Только `viewBox="0 0 24 24"`** — другая сетка ломает выравнивание в ряду бейджей.
3. **Один предмет = один смысл** — не лепи 2–3 объекта в одну иконку, не дублируй существующие метафоры.
4. **Без растровых эффектов** — ни теней, ни градиентов, ни текста; свечение даёт CSS (`box-shadow`), не SVG.
5. **Терминологический контроль** — в комментарии пиши «достижение», «навык», «ресурс»; не используй «картинка», «логотип».
6. **Проверка перед сдачей** — иконка читается в 22px, помещается в поле 3–21, id уникален.

### Условие выхода

Иконка готова, когда: `<symbol>` без `fill`/`stroke` добавлен в набор, бейдж встроен в панель, id уникален, силуэт читается рядом с `ic-book` в одном стиле. Закончи фразой: «Иконка `ic-[смысл]` добавлена — стиль набора сохранён».
