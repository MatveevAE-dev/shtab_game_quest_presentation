Для: титул, заголовок, название миссии, кнопка, логотип.
Эффект 2 · без звука
Начинающий предприниматель
Резкий набор яркости, затем возврат к спокойному свечению трубки. Мысль героя, описание, ФИО.
Резкая вспышка → спокойное свечение.
Для: основной текст, описание, мысли героя, названия объектов, подразделения, ФИО.
Эффект 3 · иконка
Включение лампы + постоянное вращение октаэдра. Цвета/заливка/толщина — ползунки выше.
Эффект 4 · акцент-как-титул
Действующие игроки: 937 тыс. субъектов МСП — 84% предприятий города.
Часть основного текста оформлена как титул (крупно, сильное свечение), без звука — как число 937 на слайде 4.

Как это ляжет в презентацию (presentation/index.html):
→ --hauss-wide (титулы) → Unbounded 800 · --hauss (текст) → Exo 2 300 · названия объектов/имя героя → Unbounded 600.
→ Эффект 1 = класс .play-boot + аудио 12.0–13.6с · Эффект 2 = .play-on · иконки-октаэдры → .oct-spin + включение.
→ Тайминги 3 скачков (keyframes neonBoot) подстроим точно под звук после утверждения.
