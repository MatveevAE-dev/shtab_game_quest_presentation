КАК ЗАПУСТИТЬ ПОКАЗ
===================

Папку "presentation" можно целиком скопировать на другой компьютер.
Всё внутри — картинки, звук и шрифты (встроены). Интернет и Python НЕ нужны.

ЗАПУСК:
- Двойной клик по "На одной волне 2026.html"  (или по "Запустить.cmd")
- Откроется в браузере по умолчанию.

ПОКАЗ НА ВЕСЬ ЭКРАН: клавиша F11.

УПРАВЛЕНИЕ:
- Клик мышью / стрелка вправо / пробел — вперёд
- Стрелка влево — назад
- Стрелка вправо / пробел — ещё и ПРОПУСКАЕТ анимацию (загрузку, разведку)

ЗВУК: сирена на слайде "Штаб" включится сама (после первого клика по показу).
Если браузер заблокировал автозвук — просто кликните один раз по странице.

СТРУКТУРА ПАПКИ:
  На одной волне 2026.html — сам показ (открывать этот файл)
  Запустить.cmd          — быстрый запуск
  assets/
    img/
      bg/                — фоновые изображения (карта, герой, кафе, cover)
      objects/           — накладываемые картинки (эскаватор, троица, скайлайн, логотип)
      intro/             — слайды вводной презентации (dpiir1..4)
    audio/               — siren.mp3 (звук сирены)
    fonts/               — fonts.css (все шрифты встроены base64)
