# Горячие клавиши презентации

Все клавиши обрабатываются в `presentation/index.html`. Почти каждая показывает **тост** (подсказку на экране) — оператор видит, что переключилось.

Клавиши с модификаторами (`Ctrl+D/L/K`) завязаны на **физическую клавишу** (`e.code`), а не на букву — работают в любой раскладке (RU/EN). `Alt`+цифры — тоже независимо от раскладки.

---

## Навигация (на любом слайде)

| Клавиша | Что делает |
| --- | --- |
| **→** или **Пробел** | Далее + **пропустить** анимацию текущего шага (доиграть мгновенно) |
| **Enter** | Далее, как клик мышью (анимацию **не** прерывает) |
| **←** | Назад |

> Клик мышью = «Enter» (далее, не прерывая). Стрелка/пробел = быстрый проскок для тех, кто уже видел анимацию.

---

## Дизайн-система: шрифт + гамма (на любом слайде)

**`Ctrl+D`** — циклом меняет режим оформления. По кругу: `off → neuro → neuro2 → neuro3 → off`. Всплывает тост с названием и описанием.

| Режим | Шрифт | Стиль |
| --- | --- | --- |
| `design=off` | HAUSS | исходный стиль текста |
| `design=neuro` | Neuropol X | неон тёплый + синий акцент |
| `design=neuro2` | Exo 2 | неон тёплый + синий акцент |
| `design=neuro3` *(по умолчанию)* | осн. текст Exo 2, заголовки/титулы Neuropol X | неон тёплый + синий акцент |

## Звук появления объектов (на любом слайде)

Звук «искра → проявление фото», который играет при выезде героя / эскаватора / скорой и т.д. Первая часть (искра) не меняется — переключается **вторая часть** (что звучит на проявлении). Нажатие сразу проигрывает пример.

| Клавиша | Звук проявления |
| --- | --- |
| **Alt+0** | Звук появления — **вкл/выкл** |
| **Alt+1** | Гудение (как было изначально) |
| **Alt+2** | Колокол |
| **Alt+3** | Рассыпающиеся искры *(по умолчанию)* |
| **Alt+4** | Воздушный выдох |
| **Alt+5** | Мягкое «пуф» |
| **Alt+6** | Тишина (только искра, без проявления) |

> Выбор живёт в `CFG.appear.snd.photo`. Чтобы зафиксировать навсегда — поменять значение в `CFG` (не только клавишей).

## Пульт громкости звука (на любом слайде)

**`Ctrl+M`** — открыть/закрыть пульт настройки громкости. Настройка «в зале». Пульт крутит **две** вещи:
- **Фоновую музыку** — свой уровень на **каждом слайде** (0–100).
- **Отдельные звуки** (появление объекта, сирена, бульдозер, драка, печать «КВЕСТ» и т.д.) — у каждого свой ползунок и кнопка **▶** (проиграть пример, чтобы услышать при настройке). Громкость звука **общая** на всю презентацию.

Сверху пульт показывает **звуки этого слайда**, ниже — остальные.

| Действие | Как |
| --- | --- |
| Открыть/закрыть пульт | **Ctrl+M** (или **Esc** — закрыть) |
| Громкость **музыки** текущего слайда | тянуть верхний **ползунок** или **↑/↓** (с **Shift** — шагом 5) |
| Громкость **звука** | тянуть ползунок в его строке |
| Прослушать звук | кнопка **▶** в строке звука |
| Перейти к другому слайду | **←/→** (пульт остаётся открытым, список звуков и уровень музыки — под новый слайд) |
| Сбросить музыку слайда на общий уровень | кнопка **«сброс музыки»** |
| Скопировать все уровни (чтобы «вшить базово») | кнопка **«копировать всё»** → в буфер |

> Всё применяется **вживую** (звук — со следующего проигрыша), значение видно на экране, **сохраняется** (localStorage) и переживает перезагрузку. Чтобы зафиксировать навсегда — «копировать всё» и вставить в `index.html`: музыку в `CFG.music.volBySlide`, звуки — в соответствующие `CFG.*.vol`. Общий уровень музыки по умолчанию — `CFG.music.vol`.

## Музыка карты: обычная ↔ Mario (на любом слайде)

**`Alt+M`** — переключает трек **карты** (слайды 3–14 и 16 — везде, кроме заставки и слайда 15) между обычным `bg-map.mp3` и **Super Mario Bros Theme** (London Philharmonic, `bg-map-mario.mp3`). Всплывает тост. Если карта звучит прямо сейчас — **живой кроссфейд** на новый файл; иначе сменится при следующем заходе на карту.

> Живёт в `CFG.music.mapAlt` (true = Mario). Чтобы зафиксировать по умолчанию — поменять флаг в `CFG`. Альт-файл тянется в кэш при первом переключении (не грузится заранее — он ~10 МБ).

**`Alt+B`** — включает/выключает **фоновую музыку на заставке** (слайд 2). По умолчанию — **выкл** (заставка тихая). Всплывает тост. Если ты сейчас на заставке — применяется сразу (кроссфейд).

> Живёт в `CFG.music.splash` (false = тихо). Маппинг `BG_SCENE.splash='load'` НЕ удалён — при включении играет тот же трек «Загрузка».

## Разбитие экрана (заставка, слайд 2)

После удара печати «КВЕСТ» экран трескается: трещины стекла из точки удара + вспышка + тряска.

**`Alt+C`** — слой трещин: **под текстом/печатью** *(по умолчанию)* ↔ **поверх текста**. Тумблер, чтобы выбрать вариант вживую. Всплывает тост.

> Живёт в `crackOver` (false = под). Зафиксировать навсегда — `z-index` у `.screen-crack` в CSS: **0** = под текстом, **30** = поверх.

## Показ фото на финале (слайд 16)

**`Alt+F`** — листает **механику показа фото** по кругу `0 → 1 → 2 → 0`:

| Режим | Что |
| --- | --- |
| **0** *(по умолчанию)* | **без показа** — только счётчик (по центру экрана) + звёзды. **Клик → финал**: закрытие вуали в центр + тёплый титул «ВСЁ ТОЛЬКО НАЧИНАЕТСЯ» / «НА ОДНОЙ ВОЛНЕ НОВЫЙ ИМПУЛЬС» по очереди |
| **1** | **киноплёнка** — фото в кадрах ленты |
| **2** | **билборды** — LED-щиты на карте, по 2 фото на щит |

Всплывает тост. Если финал уже идёт — показ пересобирается на месте (счётчик едет в центр/угол).

> Живёт в `bizPhotoMode` (по умолчанию 0). Финал режима 0 — `bizFinale()`; строки — `BIZ_FINALE_LINES`.

## Титул слайда 2 «заставка» (работают ТОЛЬКО на заставке)

**`Ctrl+L`** — листает варианты титула по кругу `0 → 1 → 2 → 0`:

| Вариант | Вид | Эффект появления |
| --- | --- | --- |
| **0** *(по умолчанию)* | лого + 3 строки (МОСКОВСКИЙ / ПРЕДПРИНИМАТЕЛЬСКИЙ / КВЕСТ) | эффект 2 (`neonOn`), поэлементно |
| **1** | лого + большое слово КВЕСТ + линии сверху/снизу | эффект 1 (`neonBoot`, розжиг, без звука) |
| **2** | дизайн-система: МОСКОВСКИЙ+ПРЕДПРИНИМАТЕЛЬСКИЙ слева + КВЕСТ справа + неон-линии + лого-водяной знак | 2 группы: слова+лого — эффект 2 сразу, КВЕСТ — эффект 1 с задержкой |

**`Ctrl+K`** — только для **варианта 2**: лого-водяной знак **вкл/выкл**.

> Стартовый вариант задаёт `CFG.style.titleVar` (0/1/2), лого вар.2 — `CFG.style.tv2Logo` (true/false).

## Замечания

- **Конфликты с браузером.** `Ctrl+L` (адресная строка), `Ctrl+K` (поиск), `Ctrl+D` (закладка) — в презентации перехватываются (`preventDefault`), но отдельные браузеры могут всё же среагировать своим действием. Если мешает — скажи, поменяем клавишу.
- Все переключатели — **временные** (на текущий показ). Чтобы зафиксировать по умолчанию — правится соответствующий флаг в блоке `CFG` внутри `index.html` (или URL-флаг: `?design=neuro2`, `?style=off`, `?logos=off`).
- Полная механика слайдов — в `SLIDES_STEPS.md`.
