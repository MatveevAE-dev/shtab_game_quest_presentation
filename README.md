# Moscow Business Quest — Штаб по защите бизнеса

Геймифицированная HTML-презентация: путь предпринимателя по Москве показан как игра-квест с уровнями. Тактический командный центр в стиле AAA-игры — карта, маршруты, объекты под замками, система достижений.

## Запуск

Открыть `index.html` в браузере. Это статическая страница (HTML/CSS/JS в одном файле), сборка не нужна.

Управление: `←/→` — слайды, клик — вперёд, `N` — заметки спикера, `M` — звук, `B` — музыка, `F` — на весь экран.

## Публикация (GitHub Pages)

Репозиторий отдаётся как статический сайт через GitHub Pages (Settings → Pages → Deploy from branch → `main` / root). Точка входа — `index.html`.

## Документация проекта

- `PROJECT_STATE.md` — состояние, план, задачи.
- `prompts/` — промпты-инструкции (сценарий, картинки, стиль иконок).
- `results/` — сгенерированный сценарий слайдов.
